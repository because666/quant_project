# 完整基线实验报告

生成时间: 2026-05-31

## 1. 数据来源说明

| 项目 | 说明 |
|------|------|
| 数据源 | akshare（A股日线前复权数据） |
| 股票池 | 2016年前上市+未退市的A股，约2589只 |
| 时间范围 | 2014-01 ~ 2024-12 |
| 训练集 | 2014-01 ~ 2020-12（766,196行，2,257只股票） |
| 验证集 | 2021-01 ~ 2022-12（232,150行） |
| 测试集 | 2023-01 ~ 2024-12（225,566行，100个调仓周） |
| 因子数量 | 52个（排除group_id/group_size和6个全零因子） |
| 数据处理 | 缺失值用列内中位数填充 |

## 2. 模型训练参数

| 模型 | 关键参数 |
|------|---------|
| LightGBM | objective=lambdarank, metric=ndcg, early_stopping=100, Optuna 20 trials |
| XGBoost | objective=rank:ndcg, early_stopping=20, Optuna 20 trials |

## 3. 实验1：标签函数对比

### 3.1 实验设计

| 组别 | 损失函数 | 说明 |
|------|---------|------|
| B-LGBM | 标准LambdaRank (NDCG) | LightGBM默认lambdarank目标 |
| E1a-LGBM | 收益加权NDCG | 增益函数替换为连续收益率加权 |
| E1b-LGBM | 收益加权NDCG + 夏普惩罚 | 加入Top-K组合夏普比率惩罚项 |
| E1c-LGBM | 收益加权NDCG + 夏普惩罚 + CVaR | 加入条件风险价值约束 |

### 3.2 实验结果

| 模型 | NDCG@10 | 年化收益 | 夏普比率 | 最大回撤 | 最优vp |
|------|---------|---------|---------|---------|-------|
| B-LGBM | 0.1549 | 13.80% | 0.492 | 17.56% | 5.0 |
| E1a-LGBM | 0.2057 | 9.92% | 0.369 | 19.41% | 5.0 |
| E1b-LGBM | 0.1479 | 13.71% | 0.532 | 13.94% | 3.0 |
| E1c-LGBM | 0.1378 | 15.90% | 0.592 | 16.03% | 3.0 |

### 3.3 结果分析

1. **NDCG@10与回测表现的反向关系**：E1a-LGBM的NDCG@10最高（0.2057）但夏普比率并非最优（0.369），E1c-LGBM的NDCG@10最低（0.1378）但夏普比率最高（0.592），表明排序准确性并不直接等价于投资绩效。

2. **CVaR感知标签函数的有效性**：E1c-LGBM夏普比率0.592优于B-LGBM夏普0.492，验证了CVaR约束对左尾风险控制的贡献。E1c-LGBM年化收益15.90%为所有方法中最高。

3. **E1b-LGBM最大回撤最低**：E1b-LGBM最大回撤仅13.94%，为所有方法中最低，表明夏普惩罚项有效降低了组合波动。

4. **最优vol_penalty差异**：B-LGBM和E1a-LGBM最优vp=5.0，E1b-LGBM和E1c-LGBM最优vp=3.0，说明引入风险感知标签后模型自身已具备波动率筛选能力，无需过高的外部波动率惩罚。

## 4. 实验2：融合策略对比

### 4.1 实验设计

| 组别 | 方法 | 说明 |
|------|------|------|
| B-LGBM | LightGBM LambdaRank 单模型 | 使用实验1的最优损失函数 |
| B-XGB | XGBoost rank:ndcg 单模型 | 使用实验1的最优损失函数 |
| E2a (AVG) | 分数平均融合 | 两模型预测分数归一化后取平均 |
| E2b (RRF) | RRF融合 | Reciprocal Rank Fusion，k=60 |
| E2c (Stacking) | Stacking融合 | Ridge元学习器 |
| E2d (W-RRF) | 加权RRF融合 | 根据验证集NDCG动态调整RRF权重 |

### 4.2 实验结果

| 模型 | 年化收益 | 夏普比率 | 最大回撤 | 最优vp |
|------|---------|---------|---------|-------|
| B-LGBM | 4.69% | 0.050 | 40.16% | 1.0 |
| B-XGB | -14.29% | -0.448 | 55.60% | 0.5 |
| E2a (AVG) | -5.03% | -0.224 | 48.71% | 1.0 |
| E2b (RRF) | -5.41% | -0.237 | 48.40% | 1.5 |
| E2c (Stacking) | 7.19% | 0.223 | 21.58% | 1.5 |
| E2d (W-RRF) | -3.17% | -0.206 | 37.69% | 2.0 |

### 4.3 结果分析

1. **B-XGB严重拖累融合策略**：B-XGB年化收益-14.29%、夏普比率-0.448、最大回撤55.60%，极端负表现是融合策略整体失败的根本原因。

2. **仅Stacking保持正收益**：E2c (Stacking) 年化收益7.19%、夏普0.223、最大回撤21.58%，其Ridge元学习器能够自动降低XGBoost的融合权重，有效缓解劣质模型的拖累。

3. **RRF类融合表现最差**：E2b (RRF) 和 E2d (W-RRF) 均出现负收益，因为RRF仅依赖排名位置，无法区分模型质量差异，劣质模型的排名信息与优质模型被同等对待。

4. **加权RRF优于标准RRF**：E2d (W-RRF, -3.17%) 优于 E2b (RRF, -5.41%)，表明根据验证集NDCG加权有一定帮助，但不足以完全消除B-XGB的负面影响。

5. **B-LGBM单模型表现优于多数融合方法**：B-LGBM年化4.69%优于E2a、E2b、E2d，说明在基线模型质量差异较大时，单模型优于融合。

## 5. 统计检验结果

### 5.1 配对t检验

- 0/15组显著（p<0.05）
- 说明：100个测试周样本量偏小，统计功效不足

### 5.2 DSR检验

- 所有方法DSR均偏低
- 表明当前样本量下各方法夏普比率的统计可靠性不足

### 5.3 检验结论

100个测试周样本量偏小，统计检验功效不足。无法在统计上确认各方法间性能差异的显著性，需更长时间窗口验证。

## 6. 与历史基线对比

### 6.1 B-XGB修复效果

| 指标 | 修复前 | 修复后 | 改善幅度 |
|------|-------|-------|---------|
| 年化收益 | -42.13% | -14.29% | +27.84pp |
| 修复措施 | - | 排除group_id/group_size + feature_names修复 | - |

### 6.2 B-LGBM修复效果

| 指标 | 修复前 | 修复后 | 改善幅度 |
|------|-------|-------|---------|
| 夏普比率 | 0.237 | 0.492 | +0.255 |
| 修复措施 | - | 52因子 + early_stopping=100 | - |

### 6.3 修复核心措施

1. **排除group_id/group_size**：这两个元信息特征导致模型过拟合，排除后泛化能力显著提升
2. **feature_names修复**：确保XGBoost使用正确的特征列，避免特征错位
3. **52因子配置**：排除6个全零因子后保留52个有效因子
4. **early_stopping=100**：LightGBM早停轮次从150调整为100，减少过拟合

## 7. 关键发现

1. **排除group_id/group_size后，模型泛化能力显著提升**：这两个元信息特征在训练集中提供了虚假的排序信号，排除后B-XGB年化收益从-42.13%改善至-14.29%，B-LGBM夏普从0.237提升至0.492。

2. **E1c-LGBM夏普0.592 > B-LGBM夏普0.492，CVaR感知标签函数有效**：在标准NDCG损失基础上引入收益加权、夏普惩罚和CVaR约束，逐步将投资目标嵌入排序学习过程，最终E1c-LGBM在夏普比率和年化收益上均优于基线。

3. **融合策略受B-XGB拖累，仅Stacking保持正收益**：B-XGB的极端负表现严重拖累了所有融合方法，仅Stacking融合（E2c）通过Ridge元学习器自动降低XGBoost权重而保持正收益7.19%。

4. **测试期100周样本量偏小，统计检验功效不足**：0/15组配对检验显著，所有方法DSR偏低，无法在统计上确认性能差异的显著性，需更长时间窗口验证。
